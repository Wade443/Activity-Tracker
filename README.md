# Daily Mood and Activity Tracker

## Project Overview
This project is a simple front end web application where users can track their daily mood and activities. The user can choose a mood, add one to three activities, save entries, view past entries, search by keyword, filter by mood, and delete entries.

The purpose of this project was to practise DOM manipulation, event handling, localStorage, and responsive web design using only HTML, CSS, and vanilla JavaScript.

## Features
1. Add a daily entry with date, mood, and activities
2. Save data in localStorage
3. View entry history
4. Search entries by keyword
5. Filter entries by mood
6. Delete individual entries
7. View simple statistics
8. Responsive layout for desktop and mobile

## Technologies Used
1. HTML
2. CSS
3. JavaScript
4. localStorage

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in a browser

You can also use a live server extension in VS Code if needed.

## Reflection
This project helped me understand how to build an interactive single page application with JavaScript. The most useful part was learning how to connect form input, DOM updates, and localStorage so that the data stays saved after refreshing the page.

One challenging part was making sure that search, filtering, deleting, and statistics all worked together correctly. I also learned how important it is to keep the code organised into smaller functions.

If I improved this project later, I would add better statistics, more mood options, and a nicer visual design.
